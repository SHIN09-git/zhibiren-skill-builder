# 学校通知执笔人

## 适用范围

用于生成校内通知类事务文档，适合面向教师、学生、家长或部门的正式通知。

## 用户输入字段

- 通知事项
- 对象范围
- 时间
- 地点
- 具体要求
- 发布单位

## 文档结构模板

1. 标题：使用“关于……的通知”。
2. 开头：说明通知背景和目的。
3. 正文：按事项、时间地点、工作要求分条列项。
4. 结尾：提示落实要求并注明发布单位。

## 文风规则

- 表述准确、稳妥、简洁。
- 缺失事实时使用【可替换占位符】。
- 不复用样本文档中的具体人名、地点、活动名和一次性安排。

## 自检清单

- 是否包含必要时间、地点、对象。
- 是否存在隐私或个案信息复用。
- 是否自行补全了未提供事实。
